Developer tools
---------------

* simple-python-project_ - Template repo for setuptools project with workflow automation
* python-daemonizer_ - Python daemonizer for Unix, Linux and OS X
* gitchangelog_ - Creates a changelog from git log history
* hexdump_ - hexdump is a slightly more tolerant binhex tool with a simple API
* pylogtailer_ - Log watching utility in python
* rpmget_ - Workflow helper to manage external RPM dependencies
* yaml-tools_ - Tools for working with YAML and other structured content
* procman_ - Console tool for running multiple external processes and multiplexing their output
* pyserv_ - Threaded wsgi, http, tftp server classes, both console entry points and daemon scripts
* doorstop-to-mermaid_ - Generate mermaid source from doorstop
* repolite_ - Manage a small set of (external) git repository dependencies with a yaml cfg
* timew-addons_ - timewarrior appindicator GUI and report extensions for timew-report
* timew-addons-sum_ - Software User Manual (from DID template) for Timew-Addons in reStructuredText => PDF
* cccc_ - Source code counter and metrics tool for C++, C, and Java
* el9-rpm-toolbox_ - extra rpm builds for el9 (centos9-stream, rockylinux9, etc)
* MIL-STD-498_ - The MIL-STD-498 DIDs, overview, GuideBook, and CDRL document in PDF format

Engineering Document Templates
------------------------------

* software_user_manual_template_ - SUM template from MILSTD-498 DID
* software_version_description_template_ - SVD template from MILSTD-498 DID
* software_test_report_template_ - STR template from MILSTD-498 DID
* software_test_description_template_ - STD template from MILSTD-498 DID
* software_design_description_template_ - SDD template from MILSTD-498 DID
